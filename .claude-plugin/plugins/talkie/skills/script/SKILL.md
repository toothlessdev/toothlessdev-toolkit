# /talkie:script

- 입력: `deck.html`, `brief.json`
- 출력: `script.json` (`${CLAUDE_PLUGIN_ROOT}/schemas/script.schema.json`)
- 발음 변환은 하지 않습니다. `display` 는 자막에 그대로 나가는 원문입니다.

## 슬라이드 파악

- 덱 코드에서 슬라이드 수, 순서, 제목, 본문, 발표자 노트를 읽습니다.
- `slideIndex` 는 덱의 슬라이드 순서이고 0부터 시작합니다. 빠지는 번호가 없어야 합니다. 말이 없는 슬라이드는 `lines` 를 빈 배열로 둡니다.

## `scriptSource` 가 `keep` 일 때

- `existingScriptPath` 의 문장을 그대로 옮깁니다. 고치거나 요약하지 않습니다.
- `existingScriptPath` 가 없으면 덱의 발표자 노트를 슬라이드별 대본으로 씁니다. 노트가 없는 슬라이드는 `lines` 를 빈 배열로 두고 결과에 적습니다.
- 대본의 슬라이드 구분을 덱의 슬라이드에 매핑합니다. 어긋나면 어긋난 곳을 결과에 적습니다.
- 빈 줄로 나뉜 문단을 기본 단위로 쓰고, 공통 절의 길이를 넘으면 문장 경계에서 나눕니다. 그래도 넘으면 쉼표에서 나누고 그 줄의 `pauseAfterSeconds` 를 `0.2` 로 둡니다. 낱말은 바꾸지 않습니다.
- 기존 대본에 화면을 읽어 주는 줄(아래 「화면을 읽어 주지 않습니다」)이 있어도 고치지 않습니다. 그런 줄의 `id` 를 결과에 적어 사용자가 고르게 합니다.
- `[잠깐 쉬기]` 같은 무대 지시는 자막에 넣지 않습니다.
  - 쉬는 지시는 앞 줄의 `pauseAfterSeconds` 에 반영합니다.
  - 그 밖의 지시는 다음 줄의 `stageDirection` 에 원문으로 남깁니다.

## `scriptSource` 가 `write` 일 때

- 슬라이드별 내용을 먼저 정합니다. `audience`, `tone`, `keyMessage` 에 맞춰 흐름을 잡고, 앞 슬라이드와 이어지게 씁니다.
- 말하는 문장으로 씁니다. 슬라이드에 적힌 글을 그대로 읽지 않고, 화면에 없는 이유와 맥락을 말합니다.
- 분량은 `targetMinutes` 에 맞춥니다. 1분에 한국어 약 390음절을 기준으로 잡습니다.
- 지어낸 수치나 사실을 넣지 않습니다. 덱과 노트에 없는 내용은 일반론으로 쓰거나 뺍니다.
- 애니메이션이 진행되는 동안 말할 줄에는 `stageDirection` 으로 무엇이 움직이는지 적습니다.

### 화면을 읽어 주지 않습니다

듣는 사람은 화면을 보면서 듣습니다. 화면만 봐도 아는 내용을 말로 되풀이하면 대본만 길어집니다.

판단 질문은 하나입니다. **이 줄을 빼면, 화면을 보는 사람이 잃는 정보가 있는가?** 없으면 뺍니다.

빼는 줄:

- 요소의 자리: 「오른쪽 위는 LLM 이고, 오른쪽 아래는 질문하는 사람입니다」, 「가운데에 지도가 있습니다」
- 생김새: 색, 모양, 크기, 개수 세기
- 화면 글자를 그대로 읽는 줄: 제목, 라벨, 캡션
- 시선 안내: 「화면을 보시면」, 「보이는 것처럼」, 「여기 있는 이 상자가」

대신 말하는 것:

- 화면에 없는 이유와 맥락: 왜 그렇게 나눴는지, 무엇이 문제였는지
- 움직임의 뜻: 칩이 날아가는 모습이 아니라 그 이동이 무슨 일인지
- 숫자의 기준: 언제 잰 값인지, 설정값인지 설명용 예시인지

| ✗ 화면을 읽음 | ✓ 화면에 없는 것을 말함 |
| --- | --- |
| 왼쪽에는 위키, GitHub, 런북 세 무더기가 있습니다. | 지식이 세 군데에 흩어져 있어서, 사람은 담당자를 찾아 묻습니다. |
| 오른쪽 위는 LLM, 오른쪽 아래는 질문하는 사람입니다. | 질문은 지도를 거쳐 LLM 으로 가고, 답에는 출처가 붙어 돌아옵니다. |
| 파란 점이 지도 위에 하나 찍혔습니다. | 숫자 목록을 좌표로 보면, 뜻이 비슷한 글끼리 가까이 모입니다. |

- 요소를 가리켜야 하면 자리 대신 이름으로 부릅니다. 「오른쪽 위 상자」가 아니라 「LLM」 입니다.
- 말과 애니메이션을 맞추는 일은 `stageDirection` 이 맡습니다. 「지금 이 점이 움직입니다」 같은 줄로 맞추지 않습니다.
- 분량을 채우려고 화면을 읽지 않습니다. 빼고 나서 `targetMinutes` 보다 짧으면 짧은 대로 두고 결과에 적습니다.
- 끝내기 전에 모든 줄에서 자리 말(왼쪽, 오른쪽, 위, 아래, 가운데, 옆), 「보이는」, 「보시면」, 색 이름을 찾아 판단 질문으로 다시 봅니다.

## 공통

- 줄 하나는 자막 한 번에 읽히는 길이로 씁니다. 한국어 60자가 넘으면 문장을 나눕니다.
- `id` 는 `s<슬라이드 번호 두 자리>-l<줄 번호 두 자리>` 입니다. 슬라이드 번호는 `slideIndex` 입니다.
- `pauseAfterSeconds` 기본값은 `0.45` 입니다.

## 끝내기

`${CLAUDE_PLUGIN_ROOT}/scripts/run.sh validate.py script --workspace <작업 폴더>` 를 통과시킵니다.
