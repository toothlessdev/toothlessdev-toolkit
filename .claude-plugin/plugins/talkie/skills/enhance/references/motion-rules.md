# 애니메이션 최소 규칙

`animate` 스킬이 없을 때 쓰는 기준입니다.

## 넣을지 정하기

- 내용을 설명하는 움직임만 넣습니다. 순서, 포함 관계, 변화, 인과를 보여 줘야 합니다.
- 설명할 게 없는 슬라이드는 그대로 둡니다.

## 움직임

- `transform` 과 `opacity` 를 우선합니다. `width`, `top` 은 레이아웃을 다시 계산하므로 피합니다.
- 들어오는 요소는 `cubic-bezier(0.22, 0.8, 0.2, 1)` 처럼 감속 곡선을 씁니다.
- 작은 요소는 `200~400ms`, 화면을 가로지르는 요소는 `600~900ms` 를 기준으로 합니다.
- 함께 움직이는 요소는 시차를 `60~120ms` 로 둡니다.

## 탐색이 깨지지 않게

- 경과 시간을 받아 화면을 그리는 함수로 만듭니다. 같은 시간을 넣으면 같은 화면이 나와야 합니다.
- CSS 애니메이션은 `document.getAnimations()` 로 시간을 맞출 수 있으므로 그대로 써도 됩니다.
- `setTimeout`, `setInterval`, 이벤트로 상태를 쌓는 방식은 쓰지 않습니다.
