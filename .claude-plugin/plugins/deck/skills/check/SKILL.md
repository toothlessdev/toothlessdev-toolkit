# 장표 내용 검사

모든 장의 화면 글자와 발표 노트를 읽고 아래 두 가지를 봅니다. 찾기만 하고 고치지 않습니다. 고칠지는 사용자가 정합니다.

만든 맥락을 모르는 눈으로 봐야 하므로, 가능하면 만든 대화와 분리된 서브에이전트에게 맡깁니다.

`(example)` 이 붙은 내용은 뜻을 보여 주는 사례입니다. 도메인, 이름, 숫자를 새 덱에 옮기지 않습니다.

## 처음 듣는 사람 기준

장마다 묻습니다.

- **이 장을 처음 들으면 무슨 말인지 아는가?** 모르겠으면 다듬기보다 빼는 쪽을 먼저 봅니다
- **이 장을 빼면 이야기가 끊기는가?** 안 끊기면 빼자고 제안합니다. 앞뒤 장과 같은 말을 하는 장도 후보입니다
- **처음 나오는 용어를 풀었는가?** 약어와 조직 안에서만 쓰는 이름은 그 자리에서 풉니다
- **예시가 말하려는 분류에 맞는가?** 예시가 다른 분류에 속하면 그 장의 논리가 무너집니다. (example) "동작이 다르다" 는 장의 예시가 사실은 구현만 다른 경우
- **나눈 구조에 이유가 있는가?** 나누거나 복제한 구조마다 왜 그렇게 하는지 답이 있어야 합니다
- **헷갈릴 개념을 짚었는가?** 비슷한 말, 같은 이름의 다른 동작, 청중이 아는 개념과의 차이를 말하고 있는지 봅니다

## 근거 기준

화면과 노트의 **모든 숫자와 단정 표현**을 뽑아 원본과 직접 대조합니다. 기억이나 이전 메모로 대조하지 않습니다.

**숫자**

- 원본(코드, 데이터, 실제 화면, 문서)에서 지금 다시 확인합니다
- 같은 뜻의 숫자가 장마다 다른지 봅니다. 기준이 다르면 하나로 통일하고 기준일을 적습니다
- 합계가 맞는지 계산합니다
- 그림의 숫자가 고정값, 설정값, 설명용 예시 중 무엇인지 구분되는지 봅니다. 근거가 언제 기준인지도 봅니다

**단정 표현**

- "누락 없음", "전부", "항상" 처럼 강한 말은 실제로 보장되는 범위로 낮춥니다
- 확인한 범위와 주장한 범위가 같은지 봅니다. (example) "목록의 파일에 모두 응답을 받았다" 는 "정책을 전부 찾았다" 가 아닙니다
- 알려진 반례가 있으면 적습니다

**적용 범위**

- "우리는 이렇게 했다" 는 말이 실제로 어디에 적용됐는지 코드나 자료로 확인합니다. 일부에만 적용한 것을 전체에 적용한 것처럼 말하지 않습니다

**아직 없는 것**

- 활용 방안이나 계획이 이미 있는 기능처럼 보이지 않는지 봅니다
- 설명용 예시와 그림이 실제 데이터처럼 보이지 않는지 봅니다. 무엇이 예시이고 언제 자료 기준인지 화면에 적혀 있어야 합니다

    > (example) LSN 번호, 페이지 배치, 어느 replica 가 늦게 응답하는지는 설명용 예시다. Replica 구성과 quorum 규칙은 2017년 AWS 자료 기준이라 지금 내부 구현은 다를 수 있다.

- 외부 사실은 출처 링크가 있는지 봅니다

**출처 구분**

- 사용자가 말해 준 것, 제가 확인한 것, 제 추정을 구분합니다. 확인 못 한 것은 사용자에게 묻습니다

## 결과

아래 열로 표를 만듭니다.

| 열                  | 적는 것                                 |
| ------------------- | --------------------------------------- |
| 장                  | 장 번호                                 |
| 항목                | 숫자, 단정 표현, 장 전체 같은 검사 대상 |
| 문제                | 무엇이 어긋났는지                       |
| 근거 또는 대조 결과 | 어디와 대조했고 무엇이 나왔는지         |
| 제안                | 고치는 방향. 고치지는 않습니다          |

(example)

| 장  | 항목    | 문제                                    | 근거 또는 대조 결과             | 제안             |
| --- | ------- | --------------------------------------- | ------------------------------- | ---------------- |
| 9   | 숫자    | 5장의 같은 지표와 집계 기준이 다름      | 원본에서 두 기준 값을 각각 확인 | 한 기준으로 통일 |
| 7   | 장 전체 | 처음 들으면 이해 어려움, 빼도 흐름 유지 | 6장과 8장이 바로 이어짐         | 삭제 후보        |

확인하지 못한 항목은 "확인 못 함" 으로 따로 적습니다. 문제가 없으면 없다고 쓰고, 어떤 숫자를 어디와 대조했는지 함께 적습니다.
