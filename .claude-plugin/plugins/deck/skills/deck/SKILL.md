# 장표 만들기

이 스킬은 순서만 정합니다. 각 기준은 역할별 스킬에 있습니다.

## `(example)` 표시

deck 플러그인의 모든 스킬은 같은 표시를 씁니다.

- `(example)` 이 붙은 표, 문장, 코드는 규칙의 뜻을 보여 주는 사례입니다. 따라 쓸 답이 아닙니다.
- 판단은 규칙 문장과 판단 질문으로 합니다. 사례와 닮았는지로 판단하지 않습니다.
- 사례에 나온 도메인, 이름, 숫자, 그림 구성을 새 덱에 옮기지 않습니다.

## 시작 전에 받을 것

그림을 그리기 전에 아래를 받습니다. 대화에 이미 있으면 다시 묻지 않습니다.

- **기준 시안**: 사용자가 좋아하는 기존 자료입니다. 없으면 없다고 확인합니다
- **이야기 흐름**: 사용자가 말할 순서입니다. 초안을 제안해도 되지만 사용자 흐름이 있으면 그것을 따릅니다
- **청중과 시간**: 누가 듣는지, 몇 분인지 확인합니다

## 만드는 순서

1. **`deck:story`**: 전체 그림과 모핑 스토리보드를 씁니다. 코드는 아직 쓰지 않습니다
2. **`deck:look`**: 시안에서 시각 규칙을 뽑고 폰트를 정합니다
3. **`deck:motion`**: 스토리보드를 구현하고 실시간 재생으로 확인합니다
4. **`deck:check`**: 처음 듣는 사람 기준과 근거 기준으로 내용을 검사합니다

스토리보드가 먼저인 이유는 모핑을 나중에 얹을 수 없기 때문입니다. 장마다 따로 그린 뒤에는 도형이 이어지지 않습니다.

## 고칠 때

사용자 지적을 보고 해당 스킬만 다시 읽습니다.

| 지적의 종류                                                             | 스킬          |
| ----------------------------------------------------------------------- | ------------- |
| 흐름이 끊긴다, 그림이 안 이어진다, 설명이 안 된다, 글자만 나온다        | `deck:story`  |
| 톤이 시안과 다르다, 밋밋하다, 폰트, 로고, 글자가 겹친다                 | `deck:look`   |
| 너무 빠르다, 부자연스럽다, 말하면서 넘기기 어렵다, 안 움직인다          | `deck:motion` |
| 무슨 말인지 모르겠다, 사실이 맞는지 의심된다, 이 장이 필요한지 모르겠다 | `deck:check`  |

## 끝낼 때 보고할 것

- 파일 경로와 여는 방법(키 조작 포함)
- 실제로 재생해 확인한 장과 확인하지 못한 장
- `deck:check` 결과 중 사용자가 판단해야 할 항목
