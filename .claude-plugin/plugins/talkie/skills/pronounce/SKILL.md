# /talkie:pronounce

- 입력: `script.json`
- 출력: `narration.json` (`${CLAUDE_PLUGIN_ROOT}/schemas/narration.schema.json`)
- 음성 모델은 영어, 숫자, 기호를 제멋대로 읽습니다. 모델에는 한글과 문장 부호만 넘깁니다.

## 규칙

- 줄마다 `{ id, speak }` 를 하나씩 만듭니다. 줄을 합치거나 빼지 않습니다.
- 같은 단어는 전체 대본에서 같은 발음으로 씁니다.
- 뜻을 바꾸거나 문장을 다듬지 않습니다. 읽는 형태만 바꿉니다.

| 원문 | 발음 |
| --- | --- |
| `XState` | 엑스스테이트 |
| `MCP` | 엠씨피 |
| `React Native` | 리액트 네이티브 |
| `fileKey` | 파일 키 |
| `92.4%` | 구십이 점 사 퍼센트 |
| `3장` | 세 장 |
| `2026년` | 이천이십육 년 |
| `4기` | 사 기 |

- 숫자는 단위에 따라 읽습니다. 장, 개, 명, 번은 고유어로, 년, 기, 학번, 퍼센트는 한자어로 읽습니다.
- 따옴표는 지우고, 말줄임표는 마침표로, 가운뎃점은 쉼표로 바꿉니다.
- 범위 `A~B` 는 「A 에서 B 사이」로 읽고, 앞뒤 숫자에 단위를 각각 붙입니다. 「A 에서 B 로」는 변화로 들려서 쓰지 않습니다.
  - `3.8~4.4초로 줄었다` → 삼 점 팔 초에서 사 점 사 초 사이로 줄었다 (✗ 삼 점 팔에서 사 점 사 초로 줄었다)
  - `123초에서 75~91초로` → 백이십삼 초에서, 칠십오 초에서 구십일 초 사이로
  - 작은 개수는 고유어로 줄입니다: `3~4개` → 서너 개
- 끝내기 전에 원문에 `~` 가 있는 줄을 모두 다시 읽어, 범위가 변화로 들리지 않는지 봅니다.

## 끝내기

`${CLAUDE_PLUGIN_ROOT}/scripts/run.sh validate.py narration --workspace <작업 폴더>` 를 통과시킵니다. 걸린 줄만 고쳐 다시 돌립니다.
