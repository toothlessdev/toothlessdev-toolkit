# 장표 시각 규칙

정해진 템플릿은 없습니다. 덱마다 기준 시안에서 규칙을 새로 뽑습니다.

`(example)` 이 붙은 내용은 뜻을 보여 주는 사례입니다. 도메인, 이름, 숫자를 새 덱에 옮기지 않습니다.

## 기준 시안에서 규칙을 뽑습니다

사용자가 준 자료를 실제로 열어 아래 값을 뽑고 짧게 적어 둡니다. 제 취향을 섞지 않습니다.

- 배경과 글자 색, 강조색과 그 쓰임
- 제목 크기와 위치, 라벨과 푸터 형식
- 그림의 도형 언어(모서리, 선, 상태 표시)
- 슬라이드 밖 조작 UI가 있는지

시안이 없으면 흰 배경, 진한 글자, 강조색 하나로 시작합니다. 강조색 기본값은 `#0078ff` 입니다. 대표 장 한 장을 먼저 보여 주고 확인받은 뒤 나머지를 만듭니다. 전부 만든 뒤 톤이 틀렸다는 말을 들으면 전부 다시 해야 합니다.

## 폰트

| 쓰임       | 폰트                         | 넣는 법                                           |
| ---------- | ---------------------------- | ------------------------------------------------- |
| 본문, 제목 | SUIT (기본)                  | `assets/SUIT-Variable.woff2`                      |
| 본문, 제목 | Pretendard (사용자가 말하면) | `assets/PretendardVariable.woff2`                 |
| 코드       | JetBrains Mono               | Google Fonts `family=JetBrains+Mono:wght@400;500` |

본문 폰트는 파일 안에 넣습니다. 발표장 네트워크에 기대지 않기 위해서입니다.

```bash
python3 -I ${CLAUDE_PLUGIN_ROOT}/skills/look/scripts/font_face_css.py <suit|pretendard>
```

이 명령이 base64 로 폰트를 담은 `@font-face` CSS를 출력합니다.

## 모든 장에 지키는 것

**뒷장도 앞장과 같은 밀도로 만듭니다.** 다 만든 뒤 모든 장을 찍어 나란히 보고, 밀도가 떨어지는 장을 찾습니다. 찍는 방법은 `deck:motion` 의 재생 확인 절에 있습니다.

**브라우저 기본 컴포넌트를 그대로 보이지 않습니다.** 슬라이더, 버튼, 입력창은 시안 언어로 직접 그립니다.

**코드는 구문 강조합니다.** 키워드, 문자열, 주석, 함수, 타입, 숫자를 구분합니다. 강조 색은 시안의 팔레트 안에서 고릅니다.

**코드 글꼴의 합자를 끕니다.** JetBrains Mono 는 `==`, `===`, `->`, `!=` 를 한 글자처럼 이어 그립니다. 연산자 개수가 내용인 덱에서는 틀린 코드처럼 보입니다. HTML 은 `font-variant-ligatures: none` 으로 끕니다. canvas 에는 합자를 끄는 설정이 없으므로 코드를 글자 하나씩 그립니다.

**세로(9:16) 무대는 휴대폰 기준으로 글자 크기를 정합니다.** 1080px 폭 무대가 휴대폰 화면에서는 약 0.36배로 보입니다.

| 쓰임                   | 무대 기준 최소 | 휴대폰에서 보이는 크기 |
| ---------------------- | -------------- | ---------------------- |
| 제목                   | 60px           | 약 22pt                |
| 본문, 코드, 도형 안 글자 | 40px         | 약 14pt                |
| 보조 라벨, 푸터        | 26px           | 약 9pt                 |

16:9 무대를 노트북이나 프로젝터로 볼 때는 이 표를 쓰지 않습니다.

**색에 뜻을 하나씩 줍니다.** 강조색은 하나로 하고, 경고색은 한 가지 뜻에만 씁니다. (example) 빨강은 실패와 누락에만 씁니다

**캡처 이미지 위에 글자를 얹지 않습니다.** 캡처 속 글자와 겹칩니다. 글자가 들어갈 영역은 직접 그리고 캡처는 잘라서 씁니다.

## 실제 자료

- 로고와 제품 화면은 실물을 씁니다. 그럴듯한 대체 도형을 그리지 않습니다
- 요청받은 항목이 전부 들어갔는지 하나씩 대조합니다
- 작업 폴더에 없으면 사용자가 쓰는 자료 저장소를 찾습니다. 그래도 없으면 없다고 말합니다. (example) 공유 드라이브, 메신저, 위키
- 합성하거나 임시로 만든 자료는 보고할 때 밝힙니다
